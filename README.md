 CodeFactory DevOps

 DESCRIÇÃO

Projeto desenvolvido para demonstrar  aplicação de práticas DevOps na empresa fictícia CodeFactory Solutions.

 OBJETIVO

Demonstrar práticas de versionamento, colaboração, documentação, containerização e Integração Contínua.

 TECNOLOGIAS ULTILIZADAS

- Python
- Git
- GitHub
- Pytest
- Docker
- GitHub Actions

 ESTRUTURA DO PROJETO

CodeFactory-DevOps/
├── src/
│   └── app.py
├── tests/
│   └── test_app.py
├── .gitignore
├── README.md
└── requirements.txt

 INSTALAÇÃO

Instale as dependências:

pip install -r requirements.txt

 Execução dos testes

Execute:

python -m pytest
